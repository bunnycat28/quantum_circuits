# Qiskit Quantum Circuits

## Overview
This repository contains quantum computing experiments implemented using Qiskit and Jupyter Notebook. It explores quantum circuit construction, circuit transpilation, and execution using IBM Quantum Runtime.

## Technologies Used
- Python
- Qiskit
- Qiskit IBM Runtime
- JupyterLab
- IBM Quantum

## Project Contents
- `qiskit_quantum_circuit.ipynb` — Jupyter notebook containing the quantum circuit implementation and experiments.

## How to Run
1. Clone or download this repository.
2. Set up Python and install the required Qiskit packages.
3. Open the notebook in JupyterLab.
4. Run the notebook cells in order.
5. If using IBM Quantum hardware, configure your IBM Quantum account and select a supported backend.

## Notes
- Some experiments may require access to IBM Quantum services.
- Execution time depends on backend availability, queue status, and circuit configuration.
- Keep API tokens and other credentials private. Never commit them to the repository.

## Purpose
This repository serves as a learning project for exploring quantum computing and Qiskit-based circuit execution.
